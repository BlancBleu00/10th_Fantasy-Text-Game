# 파일 분리 기록

기준 커밋: `1eec7ae5281382c322647f2428a37fe8f6aa7374`.

단일 index.html의 게임 코드를 25개 classic script와 CSS로 나눴습니다. index.html은 기존 DOM과 명시적인 로드 순서를 유지합니다. 모든 기본 함수 선언을 먼저 준비하고, `runtime-layers.js`에서 기존 데이터 확장과 장면 등록, 함수 래퍼를 원래 순서대로 적용합니다. 마지막 `bootstrap.js`에서 상태를 생성하고 렌더합니다.

등록 함수들은 원래 장면 객체의 callback을 그대로 보존합니다. 이전 onEnter/scene을 캡처하는 선언은 해당 등록 함수의 closure 안에서 보존됩니다. `intro_laen`은 최종 intro가 아닌 원래 라엔 장면을 참조합니다. conditionWord의 두 선언은 같은 `life-systems.js`에 원래 순서로 두어 유효 몸체를 유지합니다. localStorage 키와 저장 스키마는 유지합니다.

## 비교 검증

분리만 적용한 상태에서 원본과 **2,126개 검사**, **1,177개 선택지 실행 검사**가 일치했습니다. 284개 장면을 기본/강화 캐릭터 조건으로 실행하고, 25개 출신의 남녀 생성과 6개 탭, 리뷰 저장·복원, 인카운터 가중치와 추첨, 후속 사건, 전투, 재시작, 이전 저장 보완을 확인했습니다. 상세 결과는 `refactor-parity.json`입니다.

Node VM과 DOM 모형을 사용한 검증입니다. 실제 브라우저의 레이아웃·클릭·저장 권한은 검증하지 못했습니다. 실행 환경의 Chromium 다운로드가 실패했습니다. 기존 `manifest.webmanifest` 링크의 대상 파일도 기준 저장소에 없으며 이 분리에서는 추가하지 않았습니다.

## 별도 오류 수정

비교 검사에서 원본과 분리본 모두 16개 선택지 실행에서 `knowSuspicion is not defined`로 중단되었습니다. 기존의 의심 기록 함수인 `suspect(text)`를 호출하는 `knowSuspicion(text)` 호환 함수를 추가해 복구합니다. 상태 스키마와 기록 방식은 기존 suspect를 따릅니다.

최종 검증은 2,127개 검사에서 차이 없이 통과했고, knowSuspicion 미정의 오류는 재현되지 않았습니다. HTTP로 index.html·CSS·25개 스크립트 총 27개 리소스를 제공해 파일 바이트 일치와 정상 응답도 확인했습니다.

분리본의 회귀 검사는 원본에 같은 호환 함수를 주입한 비교 기준을 사용합니다. 실제 분리 전 원본을 수정하거나 저장한 것은 아닙니다. 잘못된 JSON 저장을 불러올 때 예외가 발생하는 기존 동작은 유지하며, 별도 개선 대상입니다.
