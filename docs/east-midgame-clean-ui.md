# 간결한 화면과 동부 중간부

## 화면

- 첫 화면: 제목과 시작 버튼. 시작을 누르면 지역 선택.
- 진행 화면: 장소, 본문, 선택지. 중요한 판정 결과·전투는 유지.
- 상태·능력·공명·관계·평판·기록·저장·불러오기·초기화는 더보기 안에 배치.
- 불러오기는 시작 → 더보기에서 접근. 이전 생성 방식은 생성 중 더보기에서 접근.
- ‘삶의 숙련’ 표시는 제거. ‘지금 이 삶이 붙잡고 있는 것’은 ‘진행 중인 사건’으로 변경.
- UI는 게임 상태/시간/난수를 변경하지 않는다. 기본 장면과 구형 저장 ID는 유지한다.
- DOM 배치만 바꾸는 compact-ui는 실제 브라우저 검사에서 검증한다. Node 가짜 DOM에서는 실행하지 않는다.

## 동부: 왕에게 가는 증언

기존 동부 초반 이후 10개 사건과 3개 중간 결말을 활성화한다.
공식 수색/짐꾼 길 → 사자 발견 → 구조/연락통 회수 → 보고 → 고개 교섭/우회 → 다음 역할.
협약(증거 3·지지 2), 역참 보호, 독립 조사 세 갈래. 게임 전체의 종장은 아니다.
확률 실패 시에도 후속 행동으로 진행하며 결과 확인 중 저장해도 재판정하지 않는다.
동부 초반의 추적·장부·지명 대조·증언 선택을 증거/지지 시작값에 반영한다.
이미 완료한 동부 초반 세이브는 기존 거점에서 수색을 시작한다. 서부·지하·체험 루트는 동부로 전환하지 않는다.

대사·현장 묘사는 기존 초안의 구현용 확장이다. 용왕의 정수, 용살자의 계보 확정,
데미갓 전투, 대륙 간 여행, 천관 전체 개방은 포함하지 않는다.
현재 동부 생성 지원 범위는 인간 출신 4종이며 다른 동부 종족 추가는 별도 작업이다.
