# 서부 중간부 — 첫 완결 경로

## 범위

지역 정식 시작의 서부만 활성화한다. 초반 3단계 종료 후 결과 화면이나
생활 거점에서 시작한다. 초반에 불참한 인물도 뒤늦게 합류할 수 있다.
동부·지하 초안은 `data/midgame.js`, `story/midgame.js`에 보존하지만
`MIDGAME_ENABLED`에 포함하지 않아 장면·진입 버튼을 등록하지 않는다.
기존 시범 장면 선택과 구형 세이브는 자동으로 정식 캠페인으로 바꾸지 않는다.

## 진행

- 허가 신청/바깥 수로 → 보증인/현장 조사 → 관측
- 일꾼 구조/옛 기록 확보 → 공동 보고 → 수문 위기
- 판정 성공이면 협약 단계, 실패/대피 선택이면 복구를 거쳐 협약 단계
- 공동 관측 협약 / 주민 보호 / 독립 조사망 중 하나로 중간부 완료

10개 사건 장면과 3개 결과 장면이다. 한 플레이에서 전부 보지는 않는다.
공동 관측 협약에는 증거 3, 지지 2가 필요하며 부족하면 버튼을 비활성화한다.
다른 두 결과는 항상 가능하다. 결과는 게임 오버나 종장이 아니다.
완료 후에도 거점 생계·휴식과 기존 서부 변경도시 콘텐츠를 이용할 수 있다.

## 공통 엔진

`state.midgame = {version:1, routes:{west:route}}`를 기존 JSON 저장에 포함한다.
route는 node/status/evidence/support/risk/history/ending/openingStance와
lastResult/lastCheck를 가진다. 상태 생성은 시작 버튼에서만 수행한다.
장면 렌더·시트 열기·확률 표시·저장 복구에는 초기화나 판정을 넣지 않는다.

초반 영향:

| 선택 | 시작 증거 | 시작 지지 |
| --- | ---: | ---: |
| 짐꾼 구조 | 0 | 1 |
| 돌아온 사람들의 말 비교 | 1 | 0 |
| 물길 실측 | 1 | 0 |
| 익명 증언 전달 | 0 | 1 |
| 미리엘 공동 조사 | 0 | 2 |
| 주민 공개 | 1 | 1 |
| 독립 조사 | 1 | 0 |
| 초반 불참 | 0 | 0 |

첫 선택·둘째 선택·입장 선택의 값을 합산한다. 증거 점수는 조사 자료의
확보 정도이지, 소문을 확정 사실로 바꾸는 기능이 아니다.

판정 확률 = 기본값 + 관련 스킬 레벨×5 + 지지×4 + 증거×3 − 위험×3,
최소 10%, 최대 95%. 기준은 플레이 검증용이며 세계관 전체 확률 엔진의
최종 밸런스가 아니다. 기존 저장형 RNG로 1~100을 한 번 뽑아 이하이면 성공.
성공 시 해당 선택의 증거·지지, 실패 시 추가 위험을 반영한다.
판정 스킬 경험치는 성공 2, 실패 1. 판정값·결과·목적지를 행동 시 저장하고
결과 확인 화면에는 재굴림을 넣지 않는다. 날짜 변경 시 기존 서부 월드 갱신은 유지한다.

행동은 기본 60분, 일부 90/120분, 복구는 180분과 기력 8을 사용한다.
거점 메뉴로 보류/재개는 물리적인 대륙 이동이 아닌 진행 메뉴 전환이며 시간이 들지 않는다.
기존 거점의 일·휴식은 원래 비용과 시간을 유지한다.
완료 플래그와 세계수 방향성 +2 보상은 마지막 선택에서 한 번만 반영한다.

## 방어와 검증

- 현재 지역·장면·node·완료 상태·pendingReview·조건을 검증한 뒤 행동한다.
- 뒤로 가기와 오래된 콜백, 연속 클릭은 보상·시간·판정을 중복 실행하지 않는다.
- 미래/과거 중간부 장면으로 go하면 저장된 node로 돌아간다.
- 다른 지역 중간부나 미등록 장면은 거점으로 돌린다.
- 기존 회귀 2,127개, 초반 1,465개, 지역 생성 1,915개 검사를 유지한다.
- `node tests/midgame.cjs`: 4개 초반 입장, 모든 가지의 성공/실패,
  세 결과, 서부 21출신×2성별, 보류·복귀, 판정 후 저장·복구와 중복 방지.
- `node tests/browser-smoke.cjs`: 데스크톱/모바일 실제 버튼 클릭으로
  생성→초반→중간부→보류→재개→실패→저장→복구→협약 결과까지 확인.

## 아직 구현하지 않은 것

세계수 내부 생명의 정체 확정, 정수 획득, 배리어 개방, 데미갓전,
동부·지하 중간부 활성화, 전 세계 독립 NPC 성장 시뮬레이션,
난이도·대륙별 불안도를 통합한 확률 엔진은 포함하지 않는다.
새 연결 사건은 제안된 구현이며 기존 설정의 확정 사실을 추가로 선언하지 않는다.
일부 본문은 관측·증언·추론을 구분하고, 미리엘을 대신해 신탁을 확정하지 않는다.
