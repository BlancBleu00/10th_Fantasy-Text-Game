# 세 지역 정식 시작 흐름

## 플레이

첫 화면 → **세 지역 중 시작할 곳을 고른다** → 지역 → 종족 → 성별 → 출신 → 이름 → 현지 프롤로그.
프롤로그에서 사건으로 들어가거나 생활부터 시작한다. 생활 거점에서도 사건에 참여할 수 있다.
첫 사건 완료/불참 후 같은 지역의 거점으로 돌아온다. 다른 라인으로 전환하는 선택 화면은 정식 시작에서 차단한다.
기존 파일럿은 첫 화면의 **이번 삶의 조건을 직접 정한다** 또는 **어디에 태어날지 운에 맡긴다**로 계속 가능하다.

| 시작 | 현재 구현된 출신 | 종족 | 초반 이후 |
|---|---|---|---|
| 베스페리아 | 기존 서부 21개 배경 | 인간·엘프·그린 오크·고블린·드워프 | 교역소 생활 / 변경도시 기존 콘텐츠 |
| 천관 | 제국 서기·강시술 가문·문파 외문제자·회색강 출신 | 인간 | 산길 역참 생활 |
| 중앙지하 | 배급소 기록원 자식·운송대 길잡이 견습 | 악마 | 중앙지하 배급소 생활 |

이는 구현된 배경 목록이다. 다른 종족이 각 대륙에 존재할 수 없다는 세계관 규칙이 아니다.
서부 출발점은 엘프 왕국 내부가 아닌 숲 **바깥** 교역소다. 중앙지하 악마는 혈통/후계자 신분을 자동 부여받지 않는다.
동부의 기존 서부 이주 설명과 서부 NPC 관계 보너스는 정식 동부 생성에 한해서 교체한다. 기존 세이브/기존 파일럿 설명은 보존한다.
악마의 능력치와 두 배경은 첫 플레이를 위한 제안이며 종족 전체의 생물학·성장 곡선·최종 밸런스를 확정하지 않는다.

## 거점과 시간

- 현지 사건 시작·이어가기·완료 기록 보기.
- 품삯: 하루 1회, 1시간, 은화 +2, 기력 -6.
- 휴식: 8시간, 기력 +20, 정신력 +5 (기존 자원 상한 적용).
- 서부 거점 ↔ 변경도시: 편도 2시간. 변경도시 생활 허브에서 교역소로 복귀 가능.
- 동부·중앙지하에서는 지역 이동 경로가 없다. 서부 장면/타 지역 메인으로 잘못 연결되면 현지 거점으로 보낸다.
- 동부·중앙지하 시간은 날짜/시각만 전진한다. 서부 감염·소문·치안 자동 갱신은 실행하지 않는다.
- 읽기·렌더·저장 불러오기는 시간과 보상을 반복 적용하지 않는다.
- 지역 HUD, 상태, 기록에 시작 지역과 메인 진행/인물 기록 표시. 서부 도시 수치가 동부·지하의 현지 지표처럼 표시되지 않는다.

## 저장과 코드

- `state.campaignDraft`: 생성 중 region/species/gender. 생성 도중 저장/새로고침/불러오기로 이어갈 수 있다.
- `state.campaign`: version=1, region, prologueDone, workDay. 생성 확정 때 기록하며 지역을 다시 선택하지 않는다.
- `state.mainOpenings`: 이전 PR의 경로 진행 상태 그대로 사용한다.
- 기존 세이브에 campaign을 자동 추가하지 않는다. PR #2 시범 진행 저장은 시범 진행으로 이어진다.
- 시작 지역과 출생권역(state.birthRegion)은 구분한다. 이름·출신·성별·출생권역은 장면 이동으로 바뀌지 않는다.
- `data/campaign-starts.js`(배경/지역), `story/campaign-starts.js`(현지 도입), `js/campaign-starts.js`(생성/거점/연결).
- 신규 파일은 main-openings 뒤, bootstrap 앞에 로드한다. data-feature 속성으로 원본 분리 검증과 기능 검증을 구분한다.

## 검증 명령

1. `node tests/refactor-regression.cjs`: 기능 확장 제외 원본 분리 동작.
2. `node tests/main-openings.cjs`: 기능 포함 39분기 및 전체 27출신의 세 라인.
3. `node tests/campaign-starts.cjs`: 54개 정식 생성 조합, 단계별 저장, 지역 격리, 중복 품삯 방지, 다음날 품삯, 불참, 서부 왕복, 구세이브, 무작위 출신 제한.
4. `node tests/browser-smoke.cjs`: Chromium 데스크톱/모바일에서 실제 클릭·새로고침·불러오기·거점·시트·가로 넘침 확인.

## 다음 범위
