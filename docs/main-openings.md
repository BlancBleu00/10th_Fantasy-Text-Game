# 세 메인스토리 초반 — 플레이 가능한 수직 시제품

정식 신규 게임 시작 흐름은 [campaign-starts.md](campaign-starts.md)를 참조한다. 아래 시범 진입 방식은 기존 파일럿과 이전 저장용으로 유지된다.

## 실행

캐릭터 생성과 출신 프롤로그 → 도입부의 **새 메인스토리 세 지역의 초반을 플레이한다** → 지역 선택.
기존 네 선택지는 유지된다. 기존 저장도 도입부에서 진입할 수 있다.

| 라인 | 첫 사건 | 첫 조사 | 입장 분기 |
|---|---|---|---|
| 서부 세계수 | 숲길과 수레의 이상 | 물길 조사 / 증언 보호 | 미리엘 협력 / 사실 공개 / 독립 |
| 동부 용왕 | 돌아오지 않은 사자 | 옛 지명 대조 / 증언 조사 | 조건부 협력 / 주민 보호 / 독립 |
| 중앙지하 후계 | 상충하는 배급 명령 | 재고 감사 / 소문 출처 | 독자 책임 / 후보 협력 / 공동 배급 |

각 라인 첫 선택에서 불참 가능. 불참은 패배가 아니다. 라인별 4장면, 선택 화면 1개로 총 13장면.
미리엘, 용왕·용살자, 악귀 후계라는 기존 축을 바탕으로 세부 사건과 대사는 이번에 새로 제안했다.
후예의 정체·세계수 진상·정수·후반 엔딩은 확정하거나 지급하지 않는다.

## 구현 경계

- 지역 선택은 **시범 장면 전환**이다. 실제 대륙 간 이동, 출생 지역 재설계가 아니다. UI에 명시한다.
- 기존 출신·성별·종족은 보존하며 모든 출신으로 시험 가능하다. 정식 시작 지역/종족 우호도 제한은 후속 통합 과제다.
- NPC는 선택별 다음 행동을 저장한다. 행동 확률·독립적인 장기 성장·다른 대륙의 병렬 진행 엔진은 아직 없다.
- 본문 읽기, render, load에 시간/보상 효과가 없다. 선택 시에만 20분(불참 5분)이 흐른다.
- 기존 advance/세계 수치를 사용한다. 정식 지역별 세계 시뮬레이션과 아직 분리되지 않았으므로 완성된 동부/지하 캠페인으로 보지 않는다.
- 완료/불참 후 같은 라인은 기록 확인만 가능하다. 반복 보상 없음. 다른 라인은 선택 화면에서 시험 가능하다.
- 상태는 `state.mainOpenings = {version:1,routes:{west,east,under}}`. 각 경로에는 step, choices, status, stance, leadStatus, lastResult가 저장된다.
- 이전 저장에 필드가 없으면 진입 시 생성한다. 기존 저장 슬롯 `fantasyFullPilot`을 유지하므로 실제 세이브는 별도 백업을 권장한다.

## 파일과 로딩

`data/main-openings.js` 메타데이터 → `story/main-openings.js` 본문·선택 데이터 → `js/main-openings.js` 상태 처리·장면 등록.
기존 runtime-layers 뒤, bootstrap 앞에 로딩한다. 기존 go/render/save/load를 교체하지 않는다.
docs/refactor-map.json은 원본 분리 검증용 목록으로 그대로 보존한다. 새 스크립트에는 data-feature 속성을 붙였다.

## 검증

- `node tests/refactor-regression.cjs`: 새 기능을 제외한 원본 분리 회귀 비교.
- `node tests/main-openings.cjs`: 실제 기능을 포함하여 39개 전체 분기 경로, 25개 출신 × 3라인, 불참·재진입·중복 클릭·저장/불러오기·구세이브 검사.
- `node tests/browser-smoke.cjs`: 원본 비교는 /parity.html, 실제 전체 빌드는 /index.html에서 데스크톱·모바일의 세 라인 클릭 및 새로고침 후 불러오기 검사.

다음 구현은 세 지역을 정식 신규 게임 출발점으로 연결하고, 출신 프롤로그와 이동 제약을 일치시키는 작업이다.
