# 문장 개선 1차

2026-10-09 게임 문장 개선 대화의 기준을 적용한다.

- 선택지는 행동 하나를 짧게 표시한다. 상세 동작과 결과는 선택 후 보여 준다.
- 장면에는 지금 판단하는 데 필요한 정보만 둔다.
- 행동과 대사로 결과를 보여 주고, 선택의 의미나 교훈을 대신 설명하지 않는다.
- 시간 정지 안내를 넣지 않는다. 행동 시간·성공률·조건은 UI에 남긴다.
- 서술은 존댓말, 선택지는 짧은 ‘~한다’ 형식으로 통일한다.
- 이전 결과는 결과 확인 화면과 기록에 보존하고 다음 본문에서 반복하지 않는다.

## 대상

세 지역 프롤로그·생활 거점·초반 12장면, 서부 중간부 13장면,
기존 사건 ‘너무 가벼운 충돌’. 다른 기존 사건 전체나 비활성 동부·지하
중간부의 문장까지 모두 고쳤다고 주장하지 않는다.

`story/prose-refresh.js`는 기존 분리 검증을 보존하는 표시 전용 덮어쓰기다.
장면/선택 ID, 선택 순서, 조건, 비용, 판정, 보상, 목적지는 바꾸지 않는다.
서부 중간부의 UI 문장은 `js/midgame.js`에서 반복 부분만 정리한다.

소매치기 추격과 압박 결과는 해당 행동의 최신 판정 로그로 성공·실패를
구분한다. 오래된 성공 플래그나 잔액으로 판단하지 않으므로 재방문이나
잔액 0에서도 이번 결과를 표시한다. 새 주사위는 굴리지 않는다.
로그 형식 의존은 `tests/prose-refresh.cjs`에서 검증한다.

## 보존 범위

기존 세이브의 기록·이미 저장된 결과 문장은 당시 내용 그대로 보존한다.
다음 행동부터 새 문장을 사용한다. 사실·의심 구분과 조사 수치도 유지한다.
새로운 종장, 추가 지역, 새 확률 엔진은 이번 범위에 포함하지 않는다.
